# MAK Lubricants Catalog — Ground-Truth Reference

This is a replication project based on the user-supplied Bharat Petroleum MAK Lubricants automobile lubricants page:

https://www.bharatpetroleum.in/our-businesses/mak-lubricants/automobile-lubricants

The reference is the visual and content source of truth. The implementation should preserve the BPCL utility links, branding, navigation, hero banner, yellow title strip, breadcrumb trail, quick-links control, the “REVVING UP PERFORMANCE USING ADVANCED CHEMISTRY” editorial section, the category catalog, and the lower continuation content and image tiles. The design should remain recognizably faithful to the source rather than introducing a new visual direction.

## Style Decisions

- Preserve the source page’s BPCL teal navigation and MAK yellow accent system.
- Preserve the editorial, image-led catalog rhythm rather than replacing it with a generic centered landing page.
- Use responsive behavior to make the same catalog legible on narrow screens without changing the content hierarchy.
- Use the source page’s wording and image assets where available; do not invent customer reviews, ratings, or testimonials.
- Add only interaction improvements needed for a catalog experience: search, category filtering, accessible mobile navigation, and image viewing.
